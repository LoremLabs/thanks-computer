workspace-browser — the workspace's own Chromium, in your browser

logs idle
open the browser polls /setup (which provisions + launches the browser stack out of band, so the request never times out), then opens a WebSocket to /screen and binds the workspace's VNC display with connect; noVNC renders it here. The page keeps polling /setup every 15s to keep the sprite awake (it idle-sleeps ~30s after the last exec).

Phase 3 — the handoff. A pony harness drives this same Chrome over CDP, navigating it every few seconds — connecting lets you watch the pony work. Click take control and the stack kills the harness: the pony's agent loop is gone, so it cannot read the page or your keystrokes while you drive (the display keeps working). Return to pony restarts the harness; closing the tab does too. Check the pony's side at /pony/act (it reports "human has control" while the harness is stopped). /logs shows the workspace logs.
