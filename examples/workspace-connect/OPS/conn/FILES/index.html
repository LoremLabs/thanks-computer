workspace-connect — a workspace-local service over one WebSocket

not connected 



  
  




  start the service runs an ordinary workspace://tools/exec that
  leaves a TCP echo server listening inside the workspace. connect opens the
  socket and its first message runs workspace://tools/connect WITH service =
  <name>; the chassis resolves the name against its own table
  (the built-in browser, plus echo added with
  TXCO_WORKSPACE_SERVICES=echo=17777) and binds the service to this
  session. From then on every frame is the service's bytes —
  no per-frame stack run. A name the table does not know is refused with the
  names it does; a service that is not running is unavailable. This is
  the transport a noVNC page rides to a workspace's browser.
