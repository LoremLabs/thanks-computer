workspace-node — a terminal on the node

the node's UI status logs not connected
A shell on the node's workspace, as the workspace's own user. The first message attaches tmux new -A -s main as a pseudo-terminal; from then on every keystroke is a WebSocket frame straight to the process — no per-key stack run. Close the tab and reconnect, and tmux resumes the same screen. The node's txco is on the path and signs as the node-local key: try txco auth whoami, txco trace last, txco versions hello. The node's files are under /var/lib/txco, and the stacks it was given under /var/lib/txco/stacks.
