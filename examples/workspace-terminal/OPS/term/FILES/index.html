workspace-terminal — a real PTY over one WebSocket

not connected
The first message attaches tmux new -A -s main to this workspace as a pseudo-terminal; from then on every keystroke is a WebSocket frame straight to the process — no per-key stack run — and the terminal's output comes back as binary frames. Resize and Ctrl-C ride the same socket as JSON control frames. Close the tab and the process dies; reconnect and tmux resumes the same screen. Try vi, top, htop.
